# CLD-tools

*The Coffin of Andy and Leyley (TCOAAL)*에서 사용하는 CLD(Coffin Language Data) 파일을 추출, 검사 및 수정하기 위한 Perl 기반 유틸리티입니다.

CLD-tools를 사용하면 게임에서 공식적으로 지원하는 사용자 번역 파일을 압축 해제하고 내부 데이터를 확인할 수 있습니다. 내장된 이미지, 폰트 및 번역 데이터를 추출할 수 있으며, 수정 사항을 CLD 파일에 적용하기 위한 리패커도 포함되어 있습니다.

## 주요 기능

- **CLD 추출:** CLD 파일을 읽고 내부 데이터를 추출합니다.
- **이미지 추출:** Base64로 인코딩된 이미지 데이터를 디코딩하고 추출합니다.
- **폰트 추출:** 내장된 폰트를 추출하며, 지정된 폰트 이름을 출력 파일명으로 사용합니다.
- **CSV 내보내기:** 계층적 키 구조를 유지하면서 번역 및 기타 데이터를 UTF-8 CSV 파일로 내보냅니다.
- **CLD 재패킹:** 번역 데이터, 이미지 및 폰트에 수정 사항을 적용합니다.

## 리패커 소개

CLD-tools에는 추출된 CLD 데이터를 수정하고 다시 CLD 파일로 빌드할 수 있는 독립적인 리패커가 포함되어 있습니다.

이 리패커는 공식 빌드 도구에 의존하지 않고 수정된 번역 데이터와 리소스를 다시 빌드할 수 있도록 개발되었습니다.

현재 리패커는 공식 빌드 도구와의 호환성을 확보하기 전까지 임시 해결책으로 제공됩니다.

공식 빌드 도구와의 호환성이 확보되면 독립 리패커는 유지보수가 중단되고 프로젝트에서 제거될 예정입니다.

## 요구 사항

- Perl 5
- JSON::PP
- MIME::Base64
- Encode
- Text::CSV
- File::Path
- File::Basename
- File::Find

## 추출기 사용법

    perl extract_cld.pl input.cld [output_folder]

출력 디렉터리를 지정하지 않으면 현재 작업 디렉터리를 사용합니다.

### 추출 결과

    output_folder/
    ├── output.csv
    ├── font.ttf
    └── imgFiles/
        └── extracted images...

실제 출력 구조는 입력 CLD 파일의 내용에 따라 달라집니다.

## 리패커 사용법

    perl cld_repack.pl input.cld output.cld [output.csv] [image_folder] [font_file]

### 인자 설명

| 인자 | 설명 | 기본값 |
|---|---|---|
| input.cld | 원본 CLD 파일 | 필수 |
| output.cld | 출력 CLD 파일 | 필수 |
| output.csv | 수정된 CSV 파일 | output.csv |
| image_folder | 수정된 이미지가 들어 있는 디렉터리 | ./img |
| font_file | 적용할 폰트 파일 | 생략 시 변경하지 않음 |

### 사용 예시

**번역 데이터 수정**

    perl cld_repack.pl original.cld modified.cld output.csv

**이미지 수정**

    perl cld_repack.pl original.cld modified.cld output.csv ./img

**폰트 수정**

    perl cld_repack.pl original.cld modified.cld output.csv ./img ./font.ttf

## 재패킹 과정

- CSV 값은 section, key, value 열을 기준으로 매칭됩니다.
- 이미지 파일은 Base64로 인코딩된 후 해당하는 기존 항목에 적용됩니다.
- 이미지 폴더 인자를 생략하면 기본적으로 ./img를 사용합니다.
- 이미지 폴더가 존재하지 않으면 이미지 수정은 건너뛰고 기존 이미지 데이터를 보존합니다.
- 개별 이미지 파일이 없거나 해당 항목을 찾을 수 없는 경우 해당 항목은 건너뛰며 기존 데이터가 보존됩니다.
- 폰트 파일은 Base64로 인코딩되며 fontFile과 fontFace가 모두 갱신됩니다.
- 폰트 파일을 지정하지 않으면 기존 폰트 데이터가 보존됩니다.
- 누락되었거나 매칭되지 않는 CSV 항목은 건너뛰며 기존 데이터가 보존됩니다.
- 원본 CLD 파일은 절대 덮어쓰지 않습니다. 모든 변경 사항은 지정된 출력 파일에 저장됩니다.

**참고:** 리패커는 실험적인 기능입니다. 항상 원본 파일의 백업을 보관하세요.

관련 법률이 허용하는 범위 내에서 저자는 소프트웨어의 오용으로 인해 발생하는 손해, 데이터 손실 또는 법적 결과에 대해 책임을 지지 않습니다.
