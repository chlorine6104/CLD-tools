# CLD-tools

Утилита на Perl для извлечения, просмотра и изменения файлов CLD (Coffin Language Data), используемых в игре *The Coffin of Andy and Leyley (TCOAAL)*.

CLD-tools позволяет пользователям распаковывать и исследовать официально поддерживаемые пользовательские файлы перевода игры. Утилита поддерживает извлечение встроенных изображений, шрифтов и данных перевода, а также включает инструмент для применения изменений к CLD-файлам.

## Возможности

- **Извлечение CLD:** Чтение CLD-файлов и извлечение содержащихся в них данных.
- **Извлечение изображений:** Декодирование и извлечение данных изображений, закодированных в Base64.
- **Извлечение шрифтов:** Извлечение встроенных шрифтов с использованием указанного имени шрифта в качестве имени выходного файла.
- **Экспорт CSV:** Экспорт данных перевода и других данных в CSV-файлы с кодировкой UTF-8 с сохранением иерархической структуры ключей.
- **Повторная сборка CLD:** Применение изменений к данным перевода, изображениям и шрифтам.

## О репакере

CLD-tools включает независимый инструмент для повторной сборки, позволяющий пользователям изменять извлечённые данные CLD и создавать на их основе CLD-файлы.

Репакер был разработан для повторной сборки изменённых данных перевода и ресурсов без использования официального инструмента сборки.

Репакер предназначен в качестве временного решения на период работы над совместимостью с официальным инструментом сборки.

После достижения совместимости с официальным инструментом сборки отдельный репакер будет снят с поддержки и удалён из проекта.

## Использование экстрактора

    perl extract_cld.pl input.cld [output_folder]

Если выходная папка не указана, будет использоваться текущая рабочая директория.

### Результат извлечения

    output_folder/
    ├── output.csv
    ├── font.ttf
    └── imgFiles/
        └── extracted images...

Фактическая структура выходных файлов зависит от содержимого исходного CLD-файла.

## Использование репакера

    perl cld_repack.pl input.cld output.cld [output.csv] [image_folder] [font_file]

### Аргументы

| Аргумент | Описание | Значение по умолчанию |
|---|---|---|
| input.cld | Исходный CLD-файл | Обязательный |
| output.cld | Выходной CLD-файл | Обязательный |
| output.csv | Изменённый CSV-файл | output.csv |
| image_folder | Папка с изменёнными изображениями | ./img |
| font_file | Файл шрифта для применения | Без изменений, если не указан |

### Примеры

**Изменение данных перевода**

    perl cld_repack.pl original.cld modified.cld output.csv

**Изменение изображений**

    perl cld_repack.pl original.cld modified.cld output.csv ./img

**Изменение шрифтов**

    perl cld_repack.pl original.cld modified.cld output.csv ./img ./font.ttf

## Процесс повторной сборки

- Значения CSV сопоставляются по столбцам section, key и value.
- Файлы изображений кодируются в Base64 и применяются к соответствующим существующим записям.
- Если папка с изображениями не указана, по умолчанию используется ./img.
- Если папка с изображениями не существует, изменения изображений пропускаются, а исходные данные изображений сохраняются.
- Если отдельный файл изображения отсутствует или соответствующая запись не найдена, эта запись пропускается, а исходные данные сохраняются.
- Файлы шрифтов кодируются в Base64, при этом обновляются оба поля: fontFile и fontFace.
- Если файл шрифта не указан, исходные данные шрифта сохраняются.
- Отсутствующие или несопоставленные записи CSV пропускаются с сохранением исходных данных.
- Исходный CLD-файл никогда не перезаписывается. Все изменения сохраняются в указанный выходной файл.

**Примечание:** Репакер является экспериментальным инструментом. Всегда сохраняйте резервные копии исходных файлов.
