# CLD-tools

[English](README.md) | [简体中文](README.zh.md) | [Español](README.es.md) | [한국어](README.ko.md)

Набор инструментов на Perl для извлечения, редактирования, повторной сборки и сравнения файлов CLD (Coffin Language Data), используемых в *The Coffin of Andy and Leyley* (TCOAAL).

TCOAAL CLD Tools позволяет просматривать и изменять пользовательские файлы перевода игры. В набор входят инструменты для извлечения диалогов, изображений и шрифтов, повторной сборки CLD-файлов и сравнения изменений.

## Возможности

- **Извлечение CLD:** извлечение диалогов и ресурсов из CLD-файлов.
- **Экспорт CSV:** экспорт данных перевода в UTF-8 CSV.
- **Поддержка шаблонов:** использование оригинального игрового `dialogue.csv` в качестве шаблона.
- **Извлечение изображений:** извлечение встроенных изображений.
- **Извлечение шрифтов:** извлечение встроенных файлов шрифтов.
- **Повторная сборка CLD:** применение изменений перевода и ресурсов к CLD-файлам.
- **Сравнение CLD:** сравнение двух CLD-файлов и отображение различий.

## Требования

- Perl 5
- Text::CSV (требуется для `cld_extract.pl`)

Остальные необходимые модули входят в стандартные дистрибутивы Perl.

## Использование экстрактора

    perl cld_extract.pl [--template dialogue.csv] <input.cld> [output_folder]

Если папка вывода не указана, используется текущая рабочая директория.

### Использование `--template`

Чтобы использовать параметр `--template`, сначала необходимо самостоятельно создать оригинальный `dialogue.csv` с помощью игрового `translator.exe`.

Затем передайте созданный CSV-файл в `cld_extract.pl` через `--template`.

    perl cld_extract.pl --template dialogue.csv input.cld output_folder

Структура шаблона, порядок записей, имена персонажей и английский текст сохраняются. Данные перевода заполняются по ID.

### Результат извлечения

    output_folder/
    ├── dialogue.csv
    ├── img/
    └── font/

Содержимое папки зависит от исходного CLD-файла.

Без `--template` создаётся базовый CSV с пустым столбцом английского текста. Этот формат также поддерживается `cld_repack.pl`.

## Использование репакера

    perl cld_repack.pl [options] <input.cld> <output.cld> [dialogue.csv] [image_folder] [font_file]

Входной и выходной файлы должны иметь расширение `.cld`. Путь выходного файла должен отличаться от пути входного файла.

### Аргументы

| Аргумент | Описание | По умолчанию |
|---|---|---|
| input.cld | Исходный CLD-файл | Обязательно |
| output.cld | Выходной CLD-файл | Обязательно |
| dialogue.csv | CSV с данными перевода | Без изменений, если не указан |
| image_folder | Папка с изменёнными PNG-изображениями | `./img` |
| font_file | Файл шрифта для добавления | Без изменений, если не указан |

### Параметры

| Параметр | Описание |
|---|---|
| `--no-images` | Удаляет все встроенные изображения. |
| `--no-font` | Удаляет встроенный шрифт и устанавливает имя шрифта `GameFont`. |
| `--font-face NAME` | Задаёт имя шрифта. |

### Примеры

**Изменение перевода**

    perl cld_repack.pl original.cld modified.cld dialogue.csv

**Изменение изображений**

    perl cld_repack.pl original.cld modified.cld dialogue.csv ./img

**Изменение шрифта**

    perl cld_repack.pl original.cld modified.cld dialogue.csv ./img ./font.ttf

**Удаление изображений**

    perl cld_repack.pl --no-images original.cld modified.cld

**Удаление шрифта**

    perl cld_repack.pl --no-font original.cld modified.cld

### Примечания по сборке

- Пустые ячейки перевода сохраняют исходный текст.
- Записи CSV сопоставляются по ID.
- Несколько последовательных строк с одинаковым ID обозначают многострочную запись.
- Новые ID не добавляются в CLD-файл.
- Отсутствующие в CSV записи сохраняют исходные данные.
- Можно заменять только уже существующие записи изображений.
- Изображения должны иметь расширение PNG и корректную сигнатуру PNG.
- Если папка `./img` отсутствует, исходные изображения сохраняются.
- Если файл шрифта не указан, исходный шрифт сохраняется.
- Если в `./font` найден ровно один поддерживаемый файл шрифта, он выбирается автоматически.
- Исходный CLD-файл не перезаписывается.

## Использование инструмента сравнения

    perl cld_diff.pl <file_A.cld> <file_B.cld>

Сравнивает два CLD-файла и показывает:

- Изменённые записи.
- Записи, присутствующие только в файле A.
- Записи, присутствующие только в файле B.

Порядок ключей объектов и пробелы в JSON игнорируются. Порядок элементов массивов учитывается.

Данные изображений и шрифтов отображаются по длине закодированных данных, без вывода их полного содержимого.

Для побайтового сравнения используйте:

    cmp file_A.cld file_B.cld

В Windows:

    fc /b file_A.cld file_B.cld
